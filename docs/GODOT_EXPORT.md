# Godot export format — `export/economy.json`

Generated by `python -m doner_balance export` (also part of `python -m doner_balance report`)
from `config/economy.yaml`. The output is deterministic (no timestamps, stable key order),
so a `git diff` of the JSON shows exactly what a balance change did.

A ready-to-use GDScript implementation lives in [`godot/economy.gd`](../godot/economy.gd)
(Godot 4.x). Copy both files into the Godot project, call `load_file()` and `self_test()`.

## Top level

| key | type | meaning |
|-----|------|---------|
| `format` | string | always `"doner-lamar-economy"` |
| `format_version` | int | bumped on any breaking change (currently `1`) |
| `economy_name`, `economy_version` | string | from the YAML (`name`, `version`) |
| `currency` | object | `{id, name, start_cash}` |
| `formulas` | object | human-readable formula strings (documentation only) |
| `staff_milestones` | array | `[{level, mult}]`, sorted by level |
| `tap` | object | `{base_value, upgrades: [TapUpgrade]}` |
| `tiers` | array | `[Tier]` in progression order (kiosk, cafe, restaurant, franchise) |
| `offline` | object | `{efficiency, cap_hours, requires_manager}` |
| `prestige` | object | see below |
| `events` | array | `[NpcEvent]` (only enabled events are exported) |
| `test_vectors` | object | expected values for verifying a port (see below) |

All money values are plain JSON numbers (64-bit floats; GDScript `float` is 64-bit too).
Times are hours where the key ends in `_hours`, otherwise seconds.

## Objects

**TapUpgrade** `{id, name, kind, value, base_cost, cost_growth, max_level}`
- `kind`: `flat` (+value coins per tap per level), `pct` (+value multiplier per level,
  additive), `income_share` (each tap also earns value × automated income/sec per level).
- `max_level`: int or `null` (no cap).

**Tier** `{id, name, index, unlock_cost, tap_mult, global_income_mult, free_staff_levels, staff, upgrades, managers}`
- `unlock_cost`: price to open the tier (the first tier is free). Tiers must be bought in order.
- `tap_mult`: tap value multiplier while this is the highest owned tier.
- `global_income_mult`: multiplies **all** income once owned (cumulative over owned tiers).
- `free_staff_levels`: `{staff_id: level}` granted when the tier is opened.
- `staff`: `[{id, name, base_cost, cost_growth, income, max_level}]` — `income` is coins/sec per level.
- `upgrades`: `[{id, name, kind, value, base_cost, cost_growth, max_level}]` — `kind` is
  `income` (price) or `speed`; both multiply the tier's automated income.
- `managers`: `[{id, name, cost, income_mult, enables_offline, offline_cap_hours_add}]` — one-time purchases.

**prestige** `{enabled, currency_name, required_tier, base_requirement, exponent, scale, bonus_per_point, min_points}`
- Selling the empire is allowed once `required_tier` is owned and the gain is ≥ `min_points`.
- Reset: cash, tiers, levels and managers go back to a new game; reputation and all-time
  earnings are kept.

**NpcEvent** `{id, name, npc, min_tier, min_hours_since_start, rate_per_hour, cooldown_hours, default_response, responses}`
- `npc`: `supplier` | `inspector` | `mafia` | `rival`.
- Eligible when the player owns `min_tier`, `min_hours_since_start` has passed since install,
  and `cooldown_hours` since the last occurrence. Arrival is Poisson: chance per second
  `1 - exp(-rate_per_hour / 3600)`. If it fires while the player is away, show it on return.
- `responses`: `[{id, name, cost: Amount, effects: [Effect]}]`.
- **Amount** `{flat, cash_fraction, income_seconds}` → `flat + cash_fraction × cash + income_seconds × income_per_sec`
  (income_per_sec = automated + tap income per second while playing). Never take more than the player's cash.
- **Effect** `{probability, income_mult, duration_hours, max_stacks, cash_loss, cash_gain}`
  - roll once with `probability`; on success apply every non-null part.
  - `income_mult` with `duration_hours` = timed modifier (re-triggering refreshes it);
    `duration_hours: null` = permanent modifier, stacking at most `max_stacks` times.
  - `cash_loss` / `cash_gain` are Amounts.

## Formulas

```
level_cost(level)   = base_cost * cost_growth ^ level            # level = already owned
bulk_cost(level, n) = base_cost * g^level * (g^n - 1) / (g - 1)
milestone_mult(L)   = product of mult over staff_milestones with L >= level
staff_income(L)     = L * income * milestone_mult(L)
tier_income         = sum(staff_income) * (1 + Σ income upgrades value*level)
                      * (1 + Σ speed upgrades value*level) * Π owned manager income_mult
global_mult         = Π owned tiers global_income_mult * (1 + reputation*bonus_per_point) * Π event income_mult
auto_income         = Σ tier_income * global_mult
tap_value           = (base_value + Σ flat) * (1 + Σ pct) * tap_mult(highest tier) * global_mult
                      + Σ income_share * auto_income
offline_cap_hours   = offline.cap_hours + Σ owned managers offline_cap_hours_add
offline_earnings    = Σ tier_income of tiers with an offline manager * global_mult
                      * efficiency * min(seconds_away, offline_cap_hours*3600)
reputation_total    = floor(scale * (all_time_earnings / base_requirement) ^ exponent)
```

## Test vectors

`test_vectors` lets the Godot port check itself (`DonerEconomy.self_test()` does this):

- `level_cost`: `[{item, level, cost}]`
- `staff_income`: `[{item, level, income}]` (around milestone boundaries)
- `reputation`: `[{all_time_earnings, reputation_total}]`
- `sample_state`: `{tiers_owned, levels, managers, reputation, expected: {global_mult, auto_income, tap_value, offline_income_per_sec, offline_cap_hours}}`
  (no event modifiers active).

## Versioning

Bump `FORMAT_VERSION` in `doner_balance/export.py` and `SUPPORTED_VERSION` in
`godot/economy.gd` for any breaking change, and update this document.
